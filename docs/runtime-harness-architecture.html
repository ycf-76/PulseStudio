中心是 ReAct 主循环的 8 个执行阶段；外围 12 个子系统按 4 条注入通道 进入内核。 每条箭头旁标注的是它真实的注入参数或构造方式，箭头指向它在循环里的生效位置。

这张图只回答一件事：子系统的入口在哪。所有箭头最终都收在 ⑤ _dispatch——它是全项目唯一执行工具的地方， 因此也是 Guardian、权限、hooks、transport 四个子系统唯一的汇聚点；而 ① 组装 messages 是技能池与上下文唯一生效的地方。 其余阶段（②③④⑥⑦⑧）不接收新子系统，只消费已注入的对象。
