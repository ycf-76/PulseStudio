# 效果层优化方案（v1.0）

> 状态：待评审 —— 用户批准前不动任何代码
> 日期：2026-10-30
> 依据：用户对 live11/live12 成片的批评（"套模板、差太远"）+ 5 个开源项目效果层调研
> （Remotion / MoneyPrinterTurbo / NarratoAI / ShortGPT / edit-greek-reel）

---

## 1. 问题定性

用户批评的原话："只会套模板""和预期差太远"。开源调研后的结论与此吻合：

**我们做的是"静态贴图 + fade"；真爆款做的是"词级时间戳驱动的进行时动效系统"
+ 写死参数区间的节奏规则。**

三宗罪（都有代码证据）：

| # | 罪状 | 证据 |
|---|------|------|
| 1 | 效果只有"出现/消失"两态 | deck/pip/decor 三链全部 `fade in/out` 或硬切，无入场动效、无进行时 |
| 2 | 装饰与内容零联动 | 素材卡按页均分/句边界定时出现，与"说到"无关 |
| 3 | 排版是大色块卡片 | `_decor_card_html` 深蓝横幅压头顶；与爆款"contrast, not decoration"（描边/阴影做对比，不贴板子）相反 |

而词级时间戳原料**早已在手**：`word_align.TimedWord(text, start, end)` +
whisper 中文字级时间戳，旧叠加动画链（OverlayPlan）已在消费
（talking_head_overlay.py:1911）——只是 deck/pip/decor 三条新链全没接。
**缺的是把词戳变成动效时钟的那一层，不是新模板。**

---

## 2. 目标效果标准（先定义"好"）

以下标准来自开源项目实测设计，作为后续所有验收的裁判规则：

1. **词级时钟**：任何屏幕元素的出现/高亮/退出，锚点是词时间戳，不是均分时间
2. **说到才出现**（edit-greek-reel）：贴图/卡片由 LLM 输出触发词，口播说到该词才
   pop 入场；停留 1.8-2.5s；每图全片只弹一次
3. **contrast, not decoration**（RemotionUI）：视觉对比靠粗描边/阴影/缩放/变色，
   不靠大色块底板
4. **量化节奏**（edit-greek-reel，写死区间杜绝即兴）：
   - 入场 pop_spring：`scale = 1 - exp(-6p)·cos(2.5πp)`，0.18s（MoneyPrinterTurbo）
   - 强调 zoom：1.08-1.10x、0.35-0.45s、全片 ≤5 次、只在数字/转折/CTA 词触发
   - motion tokens 统一：fast=0.2s / normal=0.4s / stagger=0.13s（RemotionUI）
5. **排版红线**：字幕区在画面 72% 高度带；左右安全区 80px（1080p 折算）；
   字号随文本长度自适应（fitText）；中文粗描边（白字黑边 5px 级别）
6. **声音层**：SFX 库 ≤6 音效、音量 0.15-0.2、全片不重复；zoom/贴图 pop 配卡点音

## 3. 优化项设计（按性价比排序）

### P0-1 词级 karaoke 字幕（杀伤力最大）

- **现状**：字幕（若有）整句显示；decor 模式无字幕
- **借鉴**：Remotion template-tiktok——当前词按 `fromMs<=t<toMs` 变色 + 微缩放，
  其余词白字黑描边；中文按字级 TimedWord 逐字驱动
- **设计**：
  - 数据：转录 rows（已有词级）→ `_karaoke_css(words, clip_start)` 生成
    CSS keyframes（每字两个 keyframe：变色时刻/恢复时刻），
    Playwright 渲染透明层
  - 合成：字幕层全片常驻 overlay（与素材卡同链，不再新增 ffmpeg 输入——
    字幕 PNG 序列改由一层 HTML 动画承担需要逐帧渲染，成本高；**改为
    分段静帧**：每词一组静帧只在变色瞬间换帧，竖版 30s ≈ 200-400 帧
    Playwright 截图，走现有 html_to_video 逐帧链路，实测后决定帧数上限
    降级为"逐句 karaoke"）
  - 样式：白字 + 黑描边 + 当前词品牌色（#39E508 级高亮），无底框
- **验收**：连播成片——字幕跟着说话走、当前字高亮肉眼可辨、无底色块

### P0-2 内容触发式素材卡（消灭 PPT 感的关键）

- **现状**：`_finalize_decor` 按句边界窗口贴卡，与内容无关联
- **借鉴**：edit-greek-reel：内容提及才出现、每图一次
- **设计**：
  - deck LLM prompt 增字段：每页输出 `"trigger": {"text": "老板推单",
    "mode": "word"}`（触发词/触发句片段）
  - `_finalize_decor` bounds 改为：在词流里搜 trigger.text 首次出现的
    TimedWord.start → 卡从该时刻 pop 入场，停留 min(页时长, 2.5s) 内取
    讲完该要点的时长；找不到触发词回退句边界（绝不阻断）
  - 入场动效：pop_spring 曲线写入 CSS（Playwright 渲染多帧）或 ffmpeg
    scale 表达式；v1 用 3 帧 PNG（0.5x/1.08x/1.0x）+ 0.18s 快切，视觉即
    "弹入"
- **验收**：连播——卡出现的瞬间恰是说到那句话的时刻；每卡只弹一次

### P0-3 横幅卡退役 → 轻装饰改版

- **现状**：720 宽深蓝大横幅，压头顶
- **借鉴**：contrast, not decoration；Remotion shadow 风格（阴影+渐变压暗，不加底框）
- **设计**：
  - 要点页：无底框，文字直接上画面——白字黑描边 + 顶部 20% 高度黑色
    线性渐变压暗保可读；keyword 词品牌色
  - 金句页：全大屏文字 + pop 入场（海报感），保留配图但降为右下角小图
    或删除（用户可选）
  - 尺寸：卡宽从 85% 降到 ≤60%，位置从 y=24 降到安全区内
- **验收**：连播——原片构图不被破坏；文字在任何背景上可读；无"板子感"

### P1-4 SFX 音效层

- **借鉴**：edit-greek-reel：6 音效库、adelay+amix、音量 0.15-0.2、不重复
- **设计**：`sfx/` 目录内置 6 个免版权短音效（whoosh/pop/ding/switch/riser/
  impact）；触发点=素材卡 pop、强调 zoom、转折词；ffmpeg
  `adelay`+`amix` 混入，主音频音量不变
- **验收**：连播——音效与画面动作对齐、不抢人声、不刺耳

### P1-5 强调 zoom 系统

- **借鉴**：edit-greek-reel 量化规则（1.08-1.10x / 0.35-0.45s / ≤5 次 /
  数字/转折/CTA 触发）
- **设计**：LLM 从转录标出 ≤5 个强调词（复用现有 emphasis=keyword 契约）；
  合成端对原片对应时间窗做 `scale+zoompan` 或裁切放大回贴；sqrt ease-in
  30% 峰值 + quadratic 回落
- **验收**：连播——关键数字/转折有轻微推近感，全片不超过 5 次

### P2-6 fitText + 安全区规范化

- 字号随文本长度自适应（Playwright measureText 二分字号）；
  全元素坐标收敛到安全区常量（_SAFE_MARGIN = 80 @1080 宽折算）

### P2-7 motion tokens 统一

- `_MOTION = {"fast": 0.2, "normal": 0.4, "stagger": 0.13}` 单点定义，
  所有动效时长引用它，杜绝各处随手写魔法数

## 4. 实施纪律（吸取 live 系列教训）

1. **每项独立交付、独立验收**：一项一个 commit + 一次连播验收，不再攒大招
2. **验收一律连播成片**：抽帧只能定位问题，不能宣布 PASS；成片由用户
   实看裁决
3. **每项先红后绿**：动效数学（pop 曲线/触发词搜索/窗口合成）全部纯函数 +
   单测；渲染/合成走真机
4. **降级链前置**：触发词找不到/词戳缺失/SFX 文件缺失 → 回退现有行为，
   绝不阻断出片
5. **顺序**：P0-1 → P0-3 → P0-2 → P1-4 → P1-5（字幕是地基；卡改版比触发
   机制简单先做；触发机制依赖词戳链路已热）

## 5. 风险与边界

- Playwright 逐帧渲染性能：karaoke 若逐帧截图成本过高，降级逐句 karaoke
  （句内当前词按比例高亮，视觉接近，成本 1/10）
- SFX 版权：只用免商用授权音效，入库前记录来源
- 兼容：三条链（pip/decor/旧叠加）共用效果层组件时，旧链行为不回退
- 明确不做：数字人克隆、转场模板库扩容（转场不是差距主因）、3D 动效
